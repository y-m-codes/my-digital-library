# The Odin Project Assignment: My Digital Library

## What this library does
The task is to create a simple library app that
* stores book items with their title, author, publication year, and read status;
* displays books;
* allows addition of new books;
* allows removal of books; and
* allows toggling of read status.

Additionally, I have implemented:
* sorting by title, alphabetically;
* sorting by publication year, ascending;
* searching by title or author;
* filtering by 'read' or 'unread' status;
* bulk delete; and
* bulk marking read/unread.

## Future work
I would like to additionally implement:
* space-efficient display of book tiles;
* data persistence between page refreshes; and
* libraries associated with user profiles.
